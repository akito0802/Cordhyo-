# Guitar Chord Book

スマホで見やすい、シンプルなギターコード表サイトです。

## 機能

- コード名検索
- 種類別フィルター
- 難易度別フィルター
- コードダイアグラム表示
- 構成音・響き・使い方の説明
- お気に入り保存（localStorage）
- スマホ・PC対応

## 使い方

`index.html` をブラウザで開くだけで動きます。

## GitHub Pagesで公開

1. Settings → Pages
2. Branchを `main`、フォルダを `/ (root)` に設定
3. Save

## 構成

- `index.html`
- `style.css`
- `script.js`

外部ライブラリは使用していません。
